# IL3.1: Herramientas de Observabilidad y Métricas

En este módulo aprenderás a agregar logs y métricas básicas a tus agentes de IA para monitorear su funcionamiento y desempeño.

- Ejemplo de logging y medición de tiempo de respuesta.
- Importancia de registrar eventos clave para detectar problemas.

## Notebooks de IL3.1

En esta carpeta se agregaron notebooks nuevos para trabajar la observabilidad en agentes LLM:

- `1-fundamentos_observabilidad.ipynb`: fundamentos y trazas básicas de un agente.
- `2-trazabilidad_agente_herramientas.ipynb`: análisis de un agente con herramientas y registro de spans.
- `3-observabilidad_plataformas.ipynb`: simulación de instrumentación con plataforma tipo Langfuse/Phoenix.
- `4-metricas_calidad_costo_rendimiento.ipynb`: métricas de calidad, costo y rendimiento para versiones de prompt.
- `5-debugging_errores_agentes.ipynb`: detección de fallas y análisis de trazas para corregir agentes.

**Archivo principal:** 1-observability_tools.py
